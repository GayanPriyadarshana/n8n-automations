# My Automation & Low-Code Portfolio 🚀

This repository contains a collection of production-ready **n8n** workflows designed to solve real-world business problems.

## 🛠️ Featured Automations

| Project Name | Stack | Goal |
| :--- | :--- | :--- |
| [Contact Enrichment System](./contact-enrichment-system/) | n8n, HubSpot, Apollo, GSheets | Auto-fills missing lead phone numbers in CRM. |
| [Invoice Notifier](./stripe-to-slack-notifier/) | n8n, Stripe, Slack | Alerts the team on High-Value sales instantly. |

## 🧠 Technical Skills Demonstrated
* **API Integration:** REST, Webhooks, OAuth2.
* **Data Transformation:** JSON manipulation, JavaScript Function nodes.
* **Error Handling:** Implementation of Wait nodes and Error Triggers.
